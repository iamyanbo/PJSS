PJSS CVIS draft: reproduction guide
==================================

The source ZIP retains repository-relative paths. Extract it into an empty
directory. The separate reproduction-data ZIP extracts into the same root.
The manuscript is docs/cvis2026/pjss-extended-abstract.tex.

WHAT CAN BE REPRODUCED

1. PDF, figures and numerical tables from saved evidence: fully contained in
   the source ZIP. No benchmark fitting or external baseline installation is
   necessary. All comparison counts are re-summed from per-run records, not
   transcribed percentages. The source package includes the PJSS implementation,
   baseline runners, run-selection lists and data-generation sidecars.
2. Fresh PJSS fits: use the included solver and original observations in the
   data ZIP. Current defaults are v1.2; historical v1.0 tables remain explicitly
   historical. The public version='1.0.1' option restores the older settings
   with an empty-support fix. Do not relabel a new run as an exact historical
   replay without checking the resulting coefficients and support.
3. External baselines: runners/settings are included, but third-party packages,
   pretrained weights and the historical DEDi checkout/solver shim are external.
   The original banded/Schur CHOLMOD replacement and complete historical package
   lock were not found in this checkout. Therefore exact historical DEDi refits
   are NOT claimed to be self-contained. Saved pair-level fits permit selection
   and score audits. The included native-CHOLMOD adapter is a different timing
   configuration; do not silently substitute it and claim the old timings.

ENVIRONMENT

PJSS: Python >=3.10; NumPy >=1.26, SciPy >=1.11, Numba >=0.61.
Reports/figures: threadpoolctl, matplotlib, PyMuPDF. Install from the supplied
pyproject.toml with `python -m pip install -e .`, then install these report tools.
Fresh illustration provenance records Python 3.13.13, NumPy 2.4.4 and SciPy
1.17.1, with SHA-256 for every solver module. This is NOT a lock for all earlier
benchmarks. Package minima are installation bounds, not historical pins.
PySINDy experiments used 2.1.0; ARGOS used the R package 0.1.1. DEDi GPU setup
used Python 3.12.3 and jax[cuda13] 0.12.0.1 with float64. GPU DEDi can change
support under repeated execution; see docs/reports/dedi_gpu.md.
For comparisons set OMP_NUM_THREADS, OPENBLAS_NUM_THREADS and MKL_NUM_THREADS
to 1, or use the supplied runners' threadpool limits.

METHOD IMPLEMENTATION

eqdisc/final_model.py: API, version switches, degree-weighted penalty, initial
supports and AR(1) routing. Calling eqdisc.discover(y, dt, confidence=False)
returns fitted coefficients without changing support selection.
eqdisc/joint_discover.py: midpoint objective, Huber IRLS, banded LM, Schur
quadratic, per-equation subset proposals, validation mask, spectral grid,
noise calibration, discretisation floor and fixed-support final refits.
eqdisc/joint_colored.py: AR(1) residual likelihood, conditional masked loss and
correlation-dependent penalty. eqdisc/joint_nd.py: higher-dimensional path.
eqdisc/select_k.py, flow_discovery.py and joint_squeeze.py: initial supports.
eqdisc/subset.py: subset kernels. All constants and stopping rules are in source.

NUMERICAL RECIPE AND SETTINGS

The paper explains the purpose of each stage before its mathematics. This section
retains the numerical details needed to implement or audit that explanation.
It describes the three-variable base path and its correlated-noise extension;
the higher-dimensional path is in eqdisc/joint_nd.py. Use the archived version
and run configurations when reproducing historical tables.

Inputs and joint fitting
- Observations y_i contain every state variable at uniform interval dt. Scale
  each coordinate by its RMS magnitude, without centring. The three-variable
  library has all 20 monomials up to degree three. The higher-dimensional tests
  use degree two. Library ordering is preserved in the source/data sidecars.
- Support S is the set of nonzero coefficient entries. Coefficients outside S
  are fixed at zero. Write f(x)=C^T theta(x), use latent states u_k on a grid
  with h=dt/s, observation index o(i)=i*s, and m_k=(u_k+u_(k+1))/2.
- Mask observation indices 2,5,8,... into V; T contains the rest. Minimise
    J_T = sum_(i in T,j) Huber2((u_(o(i),j)-y_(i,j))/sigma_j)
          + sum_(k,j) ((u_(k+1,j)-u_(k,j)-h*f_j(m_k))/(rho*sigma_j))^2.
  Huber2(r)=r^2 for |r|<=2 and 4*|r|-4 otherwise; rho=.03.
- Banded Levenberg-Marquardt uses at most 40 iterations and relative cost
  decrease tolerance 1e-7. Accepted steps divide damping by three; rejected
  steps multiply it by four. Initial states interpolate masked observations,
  then use Savitzky-Golay smoothing with window 21 and polynomial order three.
- Starts are supplied by a weak best-subset fit, a hybrid fit and three
  trajectory-segment alternatives. Higher dimensions use weak starts.
  Starting equations are derived from the observations, not the true support.

Profiling and support search
- Partition the Gauss-Newton matrix A and gradient g into state (u) and
  coefficient (c=vec(C)) blocks. Eliminating state increments gives
    H = A_cc - A_uc^T A_uu^(-1) A_uc
    g_tilde = g_c - A_uc^T A_uu^(-1) g_u.
  For d=c-c_star, q(c)=d^T H d + 2*g_tilde^T d, ignoring a constant shared
  by all candidates. This is the explicit form of min_(Delta u) Q in the paper.
  Use banded solves rather than forming the inverse. Symmetrise H and add
  1e-10*trace(H)/(M*D) to its diagonal. Positive-definite blocks are assumed;
  the approximation is local and does not establish global recovery.
- Project other equations' active columns out by SVD. Per equation, enumerate
  sizes zero to five and retain two candidates per size. For M=20 this is
  21,699 nonempty subsets. Normalise columns and use ridge 1e-10. Above
  250,000 combinations, use a beam of width 60.
- Combine single-equation replacements with the Cartesian product of the best
  two candidates per equation. Rank supports by min_(c outside S = 0) q(c)
  plus |S|*log(D*n). Jointly refit the ten best, starting from the current states.
  Repeat at most twice and stop if the winning fit is unchanged.
- Rank nonlinear fits by J_T + masked-observation loss + phi*kappa*log(D*n),
  where kappa=sum_((m,j) in S) w_m and
    w_m=max(.1, 1+.2*(degree_m-1.5)).
  This is a BIC-inspired heuristic, not a calibrated model probability.
  Masked observations inform preprocessing, so they are not independent future
  targets. Keep the chosen support, refit all samples, then refit with rho=.001.
  Transform coefficients back to the original coordinate units.

Noise and integration calibration
- Estimate sigma_j=MAD(Delta^4 y_j)/(.6745*sqrt(70)), with floor 1e-6 in
  scaled units. If 1.4826*MAD(y_j-u_j) is more than 10% larger, raise sigma_j
  to that residual estimate and refit the starting models.
- phi is the mean integrated residual autocorrelation, floored at one. Sum
  at most 50 lags, stopping when the correlation falls below .05.
- A Hann periodogram gives the largest coordinate peak f_p and frequency f_99
  containing 99% of signal power. Discard bins below ten times the high-frequency
  noise floor. Set
    s=clip_[2,12](max(ceil(256*f_p*dt), ceil(64*f_99*dt), 2)).
  Version 1.2 also floors sigma from the midpoint/RK4 discrepancy so that
  integration error is not treated as noise-free evidence.
- If mean lag-one residual correlation exceeds .6, use a Gaussian AR(1)
  likelihood, e_i=a*e_(i-1)+nu_i, with coordinate-specific a in [0,.97].
  For gap g between retained observations, whiten residuals by
    (e_i-a^g*e_(i-g))/(sigma*sqrt(1-a^(2*g))).
  Score masked observations conditionally on neighbours, re-estimate a once,
  and compute phi on whitened residuals. Multiply the complexity penalty by
  the mean of ((1+a)/(1-a))^(1/3).

Illustration coefficient error is ||C_hat-C||_F/||C||_F. The shorter caption in
the paper uses this same metric. Neither figure selection nor this editorial
revision changes fitted coefficients, forecasts, or benchmark records.

DATA AND PAIRED COMPARISONS

The data ZIP contains the seven original observation archives used here:
dysts_test.npz; hard120.npz; joint_sealed.npz; sealed_colored2.npz;
sealed_student.npz; sealed_colored.npz; hybrid_confirm.npz.
DATA-MANIFEST.sha256 gives exact checksums. Retain these observations for replay:
some older archive-generation seeds were not recorded. The source includes
dysts_test.json and dysts_classes.json (truth, dt, library order, initial states).
Truth is used for simulation and scoring, never support selection.

External benchmark: 77 systems, 80 runs each. Generate a fresh archive with
  python benchmarks/dysts_generate.py --classes data/dysts_classes.json --output output/replay_dysts.npz --seed 20261401
This uses LSODA, rtol=atol=1e-10, raw ODE coordinates, system-specific intervals
rounded to a 1-2-5 grid, attractor reference samples after burn-in, and Gaussian
measurement noise eta*std(clean). N=500/2000; eta=.01/.05/.1/.2; ten seeds per
cell. A numerical environment change may change a chaotic trajectory; the
original archived inputs, not regenerated trajectories, define paired runs.

Fresh full external PJSS pass (v1.2):
  python benchmarks/dysts_bench.py --method final --data data/dysts_test.npz --workers 1 --output output/replay_pjss_v12.json
This does not overwrite results_dysts/test_final.json (the historical v1.0 table).

Standard comparisons:
  python benchmarks/baselines_bench.py run --method fd_stlsq --set dysts7 --window 11 --scale raw --workers 1 --output output/replay_stlsq.json
  python benchmarks/baselines_bench.py run --method fd_sr3 --set dysts7 --window 11 --scale rms --workers 1 --output output/replay_sr3.json
  python benchmarks/baselines_bench.py run --method fd_esindy --set dysts7 --every 3 --window 11 --scale raw --workers 1 --output output/replay_esindy.json
  python benchmarks/baselines_bench.py run --method pysr --set dysts7 --every 7 --window 11 --scale rms --budget 60 --workers 1 --output output/replay_pysr.json
  python benchmarks/baselines_bench.py run --method odeformer --set dysts7 --every 3 --window 21 --beam 50 --workers 1 --output output/replay_odeformer.json
Install each external package/checkpoint first; PySR requires Julia. ODEFormer
requires its authors' pretrained checkpoint (odeformer.pt) and 200 evenly spaced
samples. Defaults/paths are documented in benchmarks/baselines_bench.py. These
rows use the default model selector or CV, not truth-based oracle selection.
Smoothed finite differences use window 11, polynomial order three. STLSQ and
E-SINDy search 55 log-spaced thresholds from 1e-4 to 1e2 in original units;
SR3 searches 41 thresholds from 1e-3 to 10 after RMS/time scaling. PySR uses
operators +, -, *, maximum expression size 35 and its "best" selector;
ODEFormer uses beam size 50 and its top candidate.
STLSQ alpha=.05. SR3 uses L0, reg_weight=threshold^2/2, relaxation=1,
max_iter=200. CV recomputes optimizers on five contiguous regression-row folds,
then scores least-squares support refits, with full-record preprocessing.
Tie-breaking favours larger thresholds. E-SINDy uses 20 bagged STLSQ models.
Random-domain weak PySINDy baselines are excluded from this draft; their old
feature seeding was not reproducible, and corrected code needs new full runs.

Core paired sample: results_h2h/order.json, seed 20261027, 16 runs per condition.
Hard = 20%, N=2000, Lorenz/Chen/Rossler. White, AR(1) a=.8 and Student-t3 =
10/20%, N=2000. Short = 5/10%, N=500. Other conditions span ten core systems.
New systems: results_rev/order_dysts.json, seed 20261030, 64 runs, eight per
noise/length cell, 35 distinct systems outside development. Use these saved
lists rather than drawing replacements after observing outcomes.
  python benchmarks/rev_ours.py --order results_h2h/order.json --output output/replay_core_pjss.json
  python benchmarks/rev_ours.py --order results_rev/order_dysts.json --truth-json data/dysts_test.json --output output/replay_new_pjss.json

DEDi external source: https://github.com/TeddyMeissner/DEDi
Runners expect an --ext directory with ext/DEDi and shim/sksparse. Both studies use
benchmarks/dedi_h2h.py; add --truth-json data/dysts_test.json for the new-system
order. For example (after restoring the external dependencies):
  python benchmarks/dedi_h2h.py --device gpu --ext <external-root> --order results_rev/order_dysts.json --truth-json data/dysts_test.json --outdir output/replay_dedi_new --worker 0
The library is the same 20-term cubic library. Grid:
lambda=10**(-3..3), R=10**(-4..0). Keep every-third-sample mask and fit all 35
pairs. Select minimum validation error or BIC, ties in the authors' loop order;
NaN scores become infinity. Historical pair records are included in the source
ZIP. Model-selection results can be audited without rerunning the optimizer.

Fast methods on the same 80 runs: benchmarks/fast_baselines.py and
benchmarks/argos_run.R. WSINDy is a port of the authors' MATLAB algorithm,
checked against Octave: K=1000, 100 log-spaced thresholds 1e-4..1, loss alpha=.8,
corner-point test functions and automatic moving-average smoothing. ARGOS uses
lasso and 200 bootstraps, not its slower default of 2000. All timing figures
compare loaded execution setups; do not interpret them as hardware-normalised.

TIMING AND OPERATION COUNTS

The displayed 14.4 s PJSS median uses the 80 later retimings in
results_fast/ours_retime_<condition>.json, including starts_seconds and a_seconds.
The 5,930 s DEDi median uses all 80 original full-grid times (73 GPU, seven CPU).
Their ratio of medians is 410.694, rounded to 411; it is not a median paired ratio.
The separate GPU-only paired ratio uses results_h2h/rows.json, filters device=gpu,
and takes median(full grid|seconds / ours_s) = 342.908, rounded to 343. Here ours_s
is the original concurrent PJSS timing. Neither statistic normalises hardware,
load or implementation. Do not label either a universal speedup or energy saving.

Operation counts come from results_anatomy/ours_h2h.jsonl (80 PJSS runs) and
results_anatomy/dedi_anatomy.jsonl (35 pairs for each of ten specified runs).
The first gives median(lm_fits)=21. For each paired run, sum DEDi lm_solves over
its 35 pairs and divide by the PJSS lm_fits; median of these ten ratios rounds to
49. The term 'joint fit' means a full nonlinear LM solve, not one LM iteration.
make_comparisons.py recalculates these values and preserves hashes and per-run
counts in evidence/comparison_counts.json. Instrumentation is implemented in
benchmarks/cost_anatomy.py; the independent report is benchmarks/anatomy_report.py.

ILLUSTRATIONS

illustration-protocol.json fixes seed 20261105, system order, 2000 training and
400 future samples. make_illustrations.py preserves RNG draws even with caches.
To refit, work in a separate extraction with only the three fresh-case .npz/.json
caches moved aside; run the script once. Do not replace cases based on outcomes.
The full causal endpoint estimator is terminal_state() in that script.
Forecast arrays exclude the initial point from RMSE and normalise by clean
training coordinate standard deviations. The gallery's saved models use a
reference-derived initial state and are NOT held-out prediction tests.
Gallery selection, integration, clipping and failure handling are recorded in
evidence/gallery/protocol.json and manifest.json. Failed cases are retained.
The compact gallery uses five panels above four centred panels; the data and
selection protocol are unchanged. Forecast and attractor discussion on page four
is checked against the cached RMSE values and the nine-case gallery manifest.

LIMITS AND SUBMISSION STATUS

The historical new-system PJSS comparison and no_schur arm preserve summary
metrics but not every fitted coefficient array, limiting independent rescoring.
The paper states these experiments as recorded findings, not as freshly rerun
experiments. Table/figure reconstruction was checked; full discovery experiments
were not repeated for this editorial revision.
The current CVIS Overleaf template remains unverified. The draft has four content
pages plus one page containing only cited references, as permitted by the current
author guidelines; this does not by itself certify CVIS template compliance.
